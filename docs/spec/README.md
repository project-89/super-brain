# Change Record Specification

The v0.7 revision package consists of:

1. [`reference/CHANGE_RECORD_SPEC_v0.6.md`](./reference/CHANGE_RECORD_SPEC_v0.6.md),
   the byte-identical verified v0.6 baseline.
2. [`CHANGE_RECORD_SPEC_v0.7_AMENDMENTS.md`](./CHANGE_RECORD_SPEC_v0.7_AMENDMENTS.md),
   the normative clauses that replace or extend v0.6.

Where the two disagree, the v0.7 amendment controls. A consolidated document is
deferred until the projection contract and second-pass findings reach the freeze
gate; this avoids presenting an unsettled trace contract as frozen.
