# Provenance

This is repository-owned delivery code based on locally observed Claude Code and
Codex transcript formats. No vendor implementation is copied or imported.

The initial format inventory observed Claude JSONL session/message lineage and
Codex JSONL session, turn, message, and tool-call records. Parsers are deliberately
tolerant of unknown source records while canonical output uses strict local
schemas. Private thinking and encrypted reasoning content are excluded.
