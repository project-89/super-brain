# @_89/fold-narrative

Fold-backed narrative projections owned by Super Brain.

The package consumes canonical `@_89/fold` events and supplies arc state,
knowledge, journey, curve, resolution-peak, and convergence queries. It has no
runtime dependency on Mythopia and does not expose a Mythopia adapter.

Pinned Mythopia data and one-time conversion code live under `test/` only. See
`test/fixtures/mythopia/PROVENANCE.md` for the evidence baseline.
